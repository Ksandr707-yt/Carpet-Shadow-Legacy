# Carpet Shadow Legacy
## ENG

Carpet Addon for bringing back Item Shadowing in modern Minecraft versions.

Originally, Carpet-Shadow was developed by [MattyMatty97](https://github.com/mattymatty97), but his project is abandoned now.

**For Minecraft versions below 1.21 please use original [Carpet-Shadow](https://github.com/mattymatty97/carpet-shadow). There is no support for original Carpet-Shadow.**

## RU

Carpet-Аддон для возвращаения механики Линковки Предметов в новые версии Майнкрафта.

Изначально, Carpet-Shadow был разработан [MattyMatty97](https://github.com/mattymatty97), но сейчас его проект заброшен.

**Для версий Майнкрафта ниже 1.21, пожалуйста, используйте оригинальный [Carpet-Shadow](https://github.com/mattymatty97/carpet-shadow). Я не оказываю помощь с Carpet-Shadow.**

# Settings/Параметры
## RU

- **shadowItemTooltip**

  Отображение уникального идентификатора Шедоу-Стака при наведении мыши на стак.

- **shadowItemFragilityFixes**

  Различные исправления, предотвращающие дюпы/разлинковки Шедоу-Стаков.

- **shadowItemUpdateFix**

  Обновление Шедоу-Стаков будет также обновлять другие стаки, даже если они находятся в других инвенатрях.

- **shadowItemPreventCombine**

  Предотвращает возможные совмещения Шедоу-Стаков между собой.

  *Работает только если активен **shadowItemFragilityFixes**.*

- **shadowItemIdSize**

  Изменяет длинну уникального идентификатора Шедоу-Стаков.

- **shadowItemUseFix**

  Предотвращает различные ошибки, связанные с использованием Шедоу-Стаков.

- **shadowCraftingGeneration**

  Добавляет возможность создания Шедоу-Стаков внутри сетки крафта с помощью эндер-сундуков.

## ENG

- **shadowItemTooltip**

  Showing unique identifier of Shadow Stack when hovering item with a mouse.

- **shadowItemFragilityFixes**

  Different changes that fix problems with Shadow Stacks unlink/dupe.

- **shadowItemUpdateFix**

  Shadow Stack update will produce another stacks update, even if they are in other inventories.

- **shadowItemPreventCombine**

  Preventing combinate of different Shadow Stacks.

  *Works only if **shadowItemFragilityFixes** activated.*

- **shadowItemIdSize**

  Changes the length of the Shadow-Stacks unique identifiers.

- **shadowItemUseFix**

  Preventing different problems with use of the Shadow-Stacks.

- **shadowCraftingGeneration**

  Adds craft of a Shadow-Stack in crafting grid with ender-chest.
